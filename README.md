# . (dot) vibes — GitHub Pages

This is a GitHub Pages-ready static prototype for `. (dot) vibes`.

## Deploy

1. Create a GitHub repository, for example `dot-vibes`.
2. Upload **all files in this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open:
   `https://YOUR-USERNAME.github.io/dot-vibes/`

## Important

- `index.html` must be in the repository root.
- `404.html` is a fallback for GitHub Pages.
- The demo uses relative paths (`./style.css`, `./app.js`) so it works in a repository subpath.
- This is a frontend prototype. Login, real audio rooms, real-time chat, video upload, gifts/coins, notifications and Play Billing require a backend and Android implementation.
